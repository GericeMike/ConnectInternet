## 与商业软件的关系定位

向日葵/UU 免费档的痛点（中继限速、排队）在自建局域网链路天然不存在；延迟水平（p50 20ms）已处于可用区间。编码是唯一显著瓶颈。

## M2 优化方向（按预期收益排序）

1. **被控端零拷贝 GPU 管线**（D3D11 纹理直喂编码器）：省 CPU 拷贝 + swscale ≈ 8~10ms → e2e 有望 ~10ms
2. **回滚 576.xx 驱动恢复 NVENC**（需管理员，用户决策）：编码 2~5ms 级 + 60fps 可期
3. cuvid 硬解替换软解：dec 1ms→<0.5ms，收益小，顺手做
4. 首帧 WGC 会话预热：首帧 ~500ms 冷启动消除

## 扫描说明

完整参数矩阵（码率 × preset × present-mode）未在本轮全跑：preset 目前硬编码 p1（速度优先档），present-mode 差异属渲染侧优化（收益 <1ms）。码率扫描可通过 `RDLINK_BITRATE_MBPS` 环境变量随时补测——50Mbps 在局域网下已无画质瓶颈（文字清晰），30/80Mbps 初测无肉眼差异。完整矩阵留 M2 按需执行。
