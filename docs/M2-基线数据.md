## 测量纪律（本轮血泪教训，后续基线必须遵守）

1. **被控端空闲是硬前提**：后台 CPU 61% 时所有性能数据无效（GPU转+读虚高 3-4 倍、
   编码虚高 5 倍、fps 腰斩，还差点据此错杀 GPU 管线）。测前 `LoadPercentage` <15%。
2. **host.exe 活着是硬前提**：黑窗口 Ctrl+C 已三次停服；测前 `tasklist` 确认。
3. A/B 切换只动 `rdlink.local.toml`（gpu_convert 开关），同一构建排除变量。
4. 复用会话的编码器状态可能粘滞（pict_type 教训）：验证编码行为必须覆盖
   新会话/复用会话/强杀重连三种形态。

## 遗留与 M3 方向

- T3b 全零拷贝（纹理直喂 QSV）：可再省 ~4ms → e2e ~6-8ms。非必需，留 M4 或空闲 spike。
- NVENC 驱动回退（用户暂缓）：NVENC 档已兼容 NV12 直喂，回退即插即用。
- M3：剪贴板同步、文件传输、电源/进程管理、**Windows 服务化**（根治黑窗口 Ctrl+C 停服，
  已三次）、密码认证、SSH 禁密码登录（待批）。
