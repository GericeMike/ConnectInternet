# M4 任务拆解：体验打磨

主题：从"能用"到"好用"。M3 已覆盖功能面（剪贴板/文件/电源/进程/认证），M4 解决
高频使用里的摩擦点：中文打不进去、多屏没法选、传文件挤视频、系统键不生效。

> 前置状态：M1/M2/M2.5/M3 全部完成（认证密码 rdlink-test-123 为测试值，建议更换）。
> 协议现状 v7。性能基线：e2e 13-15ms / 60fps / 链路瓶颈在 Wi-Fi。

## T1 IME 中文注入（1 天）

现状：协议 `InputEvent::UnicodeChar { ch }` 字段从 v1 就预留了，两端都没接线。
方案：
- client：winit `WindowEvent::Ime(Ime::Commit(text))` → 逐字符发 `InputEvent::UnicodeChar`
  （焦点在 rdlink 窗口且用户用本机输入法打字时触发；注意与本机剪贴板 Ctrl+C/V
  转发逻辑互不干扰）。
- host：SendInput `KEYEVENTF_UNICODE`（wScan=char，含代理对拆分、
  KEYEVENTF_UNICODE+UP/DOWN 序列）。
- 验收：被控端记事本输入"你好世界🍎"（含 emoji 代理对）逐字正确；英文键盘
  直击行为不回归。

## T2 多显示器 + DPI（2 天）

- T2.1 枚举与选择：host `--list-monitors` 扩展 + 会话握手协商捕获哪块屏；
  面板加显示器切换下拉（协议 v8：VideoStreamInfo/Hello 带显示器标识，
  或复用控制消息动态切换——推荐后者，免重连）。
- T2.2 跨屏映射：client 坐标归一化按所选屏边界换算（现实现只按主屏 1920x1080）。
- T2.3 DPI：两端进程声明 Per-Monitor DPI aware；混合分辨率（主控 1440p240 +
  1080p144）下 client 窗口缩放与坐标映射验证。
- 验收：远端接双屏 → 面板切换捕获屏 → 画面/坐标正确；缩放 125%/150% 混搭坐标不偏。

## T3 码率自适应 + 传输隔离（1.5 天）

- T3.1 链路感知降档：client 统计窗口内丢帧率/队列深度回传（Pong 扩展或统计帧），
  host 运行时改编码码率（ffmpeg 软参数热调；档位 50/30/15/8 Mbps）。
- T3.2 传输降档联动：文件传输进行中自动降至 15Mbps，传完恢复（消除"传文件视频卡"）。
- 验收：限速 20Mbps（Wi-Fi 弱信号场景）下视频可用；传输期间视频仍可操作。

## T4 文件传输增强（2 天）

- T4.1 全盘浏览：面板文件列表支持目录导航（FileListReq.path 已预留）+
  上传落点改为"拖到哪个窗口落哪"（已实现）+ 面板可选目录。
- T4.2 多文件队列：多选拖入串行队列 + 汇总进度。
- T4.3 断点续传：Chunk offset 续传（协议已带 offset，需 host 侧半成品文件保留与
  重开校验）。
- 验收：断网重连后续传不重头；10 个文件队列顺序完成。

## T5 文件剪贴板（1 天）

方案（简化版）：本机复制文件（CF_HDROP）→ client 检测到文件列表 → 自动走上传通道
落对端 Downloads + 面板提示"已上传 N 个文件，可在被控端 Downloads 查看"。
反向同理。真正的"对端粘贴到任意文件夹"依赖远端 Shell 集成，标记 M5 评估。

## T6 系统键转发（1 天）

- Alt+Tab / Win 键 / Ctrl+Alt+Del 组合的处理策略：
  - Alt+Tab、Win：SendInput 可注入（host 非提权即可）→ 直接透传（client 侧拦截
    本地语义，改为转发）。
  - Ctrl+Alt+Del：安全序列无法软件注入（设计如此），面板提供"锁屏/任务管理器"
    替代按钮（任务管理器已在 M3-4）。
- 验收：远端 Alt+Tab 切窗、Win 键开开始菜单生效。

## T7 运维杂项（0.5 天）

- client 控制台窗口隐藏（wscript 方案与被控端对齐）+ 日志落文件。
- host 控制循环清理 7 个警告（unused doc comment/变量）。
- rdlink.toml 注释补全（auth/download_dir 等新字段说明）。

## T8 跨网访问 → 升级为 M5（独立里程碑）

原始需求"预留跨网能力"。体量大（中继服务器/打洞/安全暴露面），不建议塞进 M4：
- 方案选型：自建中继（VPS+QUIC 转发） vs P2P 打洞 vs Tailscale 组网 vs FRP。
- 认证基础已有（证书 pinning + 密码认证 v7），跨网必须启用密码 + 强制改默认密码。
- 安全评审：暴露面/审计/防爆破（M3-5 已有 3 次失败冷却，需加固为持久封禁）。
建议 M3 收官稳定运行一段时间后单独立项。

## 执行顺序建议

T1（1 天见效）→ T2 → T3.2（先做传输降档联动，缓解已知卡顿）→ T4 → T5 → T3.1 → T6 → T7
每任务保持既有节奏：实现 → 本地回环 → 双机部署 → 实测验收 → 提交同步。
